# Retail-Sales-Dashboard-5Days
# 📊 5 Days Sales Performance Dashboard

## 📌 Project Overview
This project is an interactive Microsoft Excel dashboard designed to analyze the sales performance of sales executives over a 5-day period. The dashboard helps monitor sales, compare targets, and evaluate individual performance.

## 🎯 Objective
- Track daily sales performance
- Compare actual sales with targets
- Measure target achievement percentage
- Identify top-performing sales executives
- Monitor regional sales performance

## 📂 Dataset
The dataset contains the following fields:
- Emp Code
- Sales Executive
- Region
- Day 1 Sales
- Day 2 Sales
- Day 3 Sales
- Day 4 Sales
- Day 5 Sales
- Total Sales
- Target
- Target Hit %
- Away From Target %

## 🛠️ Tools Used
excel
data-analysis
sales-dashboard
dashboard
pivot-table

## 📈 Dashboard Features
- Total Sales Analysis
- Target vs Actual Sales
- Target Hit %
- Away From Target %
- Region-wise Performance
- Sales Executive Performance
- Interactive Filters (Slicers)
